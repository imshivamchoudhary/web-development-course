CSS Shadows

CSS Shadows are used to give a visual shadow to any element.

I am a div. 
 box-shadow: h-offset v-offset blur spread color inset;
  • h-offset & v-offset : Determine the shadows horizontal and vertical position.
  • blur: The large the value ,the blurrier the shadows
  • Spread: Expands or shrinks the shadow size.
  • inset:Makes the shadow inner.

here is an example:

.div{ box-shadow: 5px 5px 15px 5px #888888;}

Outline

An outline is a line that is drawn around a element, outside the borders , to make the element "stand out ". It's commonly used for accessibilty purpose, like hightlighting focused element

Syntax for outline;

outline: width style color;

  • width: Set the outline width.
  • style: Determine the style of the outline such as solid,dotted ,or dashed.
  • color:Sets the outline color.
