CSS Box Model

The css box model defines how elements are rendered and how their dimension are calculated. It describe the structure of an element as a rectangular box that has content,padding a border and a margin. The box model consist of four components which are.

1.Content

  • The inner most component of the box model is the actual content of the element it can be text,image ,video,etc
  • The content area is define by the width and height properties.
