CSS Box Model

The css box model defines how elements are rendered and how their dimension are calculated. It describe the structure of an element as a rectangular box that has content,padding a border and a margin. The box model consist of four components which are.
The CSS Box Model can be visually represented as :

Calculate the total dimension of the element:

The total width and height of the element is calculated with formula :
  • total width =width+ left padding + right padding + left border + right border+left margin + right margin
  • Total height = Height + Top padding + Bottom padding + Top border + Bottom border + Top margin + Bottom margin

1.Content

  • The inner most component of the box model is the actual content of the element it can be text,image ,video,etc.
  • The content area is define by the width and height properties.

2.Padding

  • The space between the actual content and the border of the element is the padding.
  • The padding area is define by the property of padding.

3.Border

  • The border surrounds the content and padding and gives the visual border of the element.
  • The border properties can be controlled by using border keyword.

4.Margin

  • The margin is the space outside the element that seperates it from other element in the layout.
  • The margin of the element is controlled by the margin property.
